# G2Market Platform

## Vision

G2Market is an AI-powered shopping and package forwarding platform that enables customers worldwide to shop from India, receive a virtual Indian address, consolidate packages, and ship internationally.

---

## Core Services

- Virtual Indian Address
- Package Forwarding
- Personal Shopper
- International Courier
- Warehouse Storage
- Returns Management

---
