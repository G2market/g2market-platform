# G2Market Platform - System Architecture

Version: 1.0

---

# Overview

G2Market is an AI-powered shopping and package forwarding platform that allows customers worldwide to purchase products from India and receive them through a secure virtual Indian address.

The platform consists of four major applications sharing a common backend.

---

# Applications

Purpose:

Marketing, SEO and customer acquisition.
